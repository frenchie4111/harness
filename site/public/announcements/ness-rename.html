Harness is now Ness

Harness
until today
Ness
same app

We’ve decided to rename harness to ness. The biggest reason is that I (mike) got tired of trying to explain that “Harness” is an IDE that I build for running other harnesses. The old name was clever, but a bit too clever

In theory you shouldn’t have to do anything for the rename. I tried to make it backwards compatible in all the ways I could find. Some config files will still be named Harness unless you rename them manually to ness. But of course if you have any problems at all, feel free to leave an issue on github

Also, if you are interested in being part of the future of ness, join the slack!
