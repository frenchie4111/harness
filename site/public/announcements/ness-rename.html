Harness is now Ness.

New name, new mark, same app. Your settings, worktrees, token and pane layout come with you — there is nothing you need to do.

Harness
until today
Ness
same app

Your config directory never moved. Neither did anything else.

Why the name changed

"Harness" was already taken, and taken well. There is a large, well-funded DevOps company by that name, and it owns the search results for it completely. Every attempt to send someone here started with a paragraph explaining which Harness we meant, and ended with them landing somewhere else.

A name you have to disambiguate isn't a name. Ness is short, it's ours, and it's what was left when you take the "har" off the front — which is roughly how the project already got referred to out loud.

Nothing is required of you

Auto-update carries you across. The rename deliberately did not touch anything that stores your data — the app's data directory and its keychain identity are pinned to their original values precisely so that a name change can't orphan a single byte of your setup.

Settings and preferences

Theme, hotkeys, fonts, UI scale, agent interface — all read from the same config.json they always did.

Your GitHub token

Still encrypted at rest under the same keychain entry. PR status keeps working without a re-paste.

Worktrees and repos

Every worktree Ness knows about is still there, still grouped, still sorted by PR status.

Pane and tab layout

Splits, tab order and which terminal was where all restore exactly as you left them.

One cosmetic wart on macOS

If you auto-update, the app in your Applications folder will still be called Harness.app. macOS updates replace the app in place, at the path it already lives at — so the bundle keeps its old filename and its old icon in Finder and the Dock, even though everything inside it is the new build.

This is harmless and it is not a failed update. If the old name bothers you, download the current release once and drag it over; you'll get Ness.app with the new icon, and it will pick up all of the same settings. Otherwise, ignore it.

The new mark

The dot grid is gone. In its place is a small green creature surfacing out of a loch, which is the joke the name was always going to demand. It's a single flat green — #4ade80 — and it now runs through the whole app: the titlebar, focus rings, the pending-worktree pulse, the icon in your Dock.

The green is also configurable. Settings → Appearance → Nessie's colour repoints the app's primary colour if you'd rather it matched your terminal theme than ours.

What's next

The repository is moving to its own GitHub organisation, and the site will follow it to a dedicated getness.dev domain. Neither is live yet. When they are, the current links will redirect and we'll say so here first — nothing you have bookmarked or cloned is going to break without warning.

Until then everything stays where it is: the repo, this site, and the update channel your app is already pointed at.
